# Match analyzer tool

This is the future home of the Agent Tuning Studio's evidence-analysis
adapter.

## Responsibility

- Retrieve completed run evidence.
- Validate provenance and matched controls.
- Compare economic outcomes and behavior metrics.
- Inspect decision traces and calibration evidence when available.
- Return bounded findings and unresolved uncertainty for human review.

Creating or displaying a match belongs to the sibling
[`../matchmaker/`](../matchmaker/) tool. No analyzer implementation exists
yet.
